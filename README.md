## How it works

`main.ts` (Node, stdlib only) writes the line above, byte-exact with no
trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
The line is 150 characters, one line, inside the 1–200 gate.

