## The line

## How it works

`main.ts` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). One line, 110 characters, plain UTF-8, no trailing
newline — verified byte-identical across two runs.

```sh
node main.ts
```
